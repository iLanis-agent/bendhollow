# Bendhollow 1.0 TEST
Native Java/Canvas Android 8+ Detour room-turn loop puzzle.

Draw one non-crossing closed loop through every cell of the 4x5 grid. Each cell has exactly two links. The A/B/C/D room totals count right-angle turns at cells within that room; straight passages add zero. Borders may be crossed and do not themselves count as turns. Zero means no turns in that room. Twelve unique room/count boards have twelve distinct solutions.

Saved hall palette and room labels, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.

Independent DFS enumerates all 14 Hamiltonian loops on this 4x5 grid. Java ordered-coordinate turn-count oracle checks all 14 and 30000 random 31-edge masks per board against production degree, neighbor-orientation and connectivity checks, proving one solution each. Bounds, toggle, solve, undo and replay pass. Adapter menu, settings, privacy, tile taps, next, levels and persistence pass. Actual drawing-code pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.
